# Document Continuity Assistant (DCA)

## Overview

Document Continuity Assistant (DCA) is a research prototype designed to support knowledge continuity during organizational handover in student organizations.

The system aims to help succeeding members discover organizational documents, understand their context, retrieve relevant evidence, and use prior knowledge to support task execution and adaptation.

## Research Context

This project is developed as part of an undergraduate thesis using a Design Science Research (DSR) approach.

The artifact is informed by interview findings, synthesized design requirements, and candidate design principles.

## Project Scope

The prototype focuses on:

- Organizational and program context management
- Document discovery and lifecycle management
- Evidence-grounded information retrieval
- Contextual answers with source references
- Handover support through task guidance and comparison
- Knowledge capture and learning records
- Technical and task-based evaluation

## Technology Stack

- Python
- FastAPI
- SQLite
- Qdrant
- OpenAI API
- HTML, CSS, and JavaScript

The technology stack and implementation details may evolve through documented development decisions.

## Development Status

This project is under active development. Features, evaluation results, and design principles are not considered validated until supported by documented evidence.
